
### 多维度限流



限流 Lua 脚本的加载机制，采用静态加载 + 运行时注册的两阶段初始化策略



```plainText
┌─────────────────────────────────────────────────────────────┐
│                    初始化时序                               │
├─────────────────────────────────────────────────────────────┤
│  类加载阶段                  │  Bean 初始化阶段              │
│  ┌─────────────────────────┐ │  ┌───────────────────────┐  │
│  │  static {} 块执行        │ │  │  @PostConstruct      │  │
│  │  读取 Lua 文件到内存     │ │  │  获取 RScript 对象    │  │
│  │  LUA_SCRIPT = "..."     │ │  │  scriptLoad()        │  │
│  └─────────────────────────┘ │  │  ↓                   │  │
│                              │  │  Redis SCRIPT LOAD   │  │
│                              │  │  返回 SHA1           │  │
│                              │  └───────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```
为何采用两阶段加载？

阶段	原因
静态加载	Lua 脚本是静态资源，类加载时即可读取，避免重复 IO
运行时注册	Redis 连接需要依赖注入完成后才能使用，不能在静态块中操作
性能优势：

脚本内容只读取一次（类加载时）
脚本只注册一次（Bean 初始化时）
执行时通过 SHA1 引用，减少网络传输量
