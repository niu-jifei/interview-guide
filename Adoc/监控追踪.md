
## Micrometer Observability 框架

### ObservationRegistry
1. 监控指标收集: 收集应用程序的性能指标，如响应时间、请求频率等
2. 分布式追踪: 在微服务架构中追踪请求的完整路径
3. 可观测性: 提供对应用程序运行状态的可见性

### 使用
#### 1. 引入依赖
```xml
<!-- Maven -->
<dependency>
    <groupId>io.micrometer</groupId>
    <artifactId>micrometer-observation</artifactId>
</dependency>
<dependency>
    <groupId>io.micrometer</groupId>
    <artifactId>micrometer-tracing-bom</artifactId>
    <type>pom</type>
    <scope>import</scope>
</dependency>
<dependency>
    <groupId>io.micrometer</groupId>
    <artifactId>micrometer-tracing-bridge-otel</artifactId>
</dependency>

```

```text
implementation 'io.micrometer:micrometer-observation'
implementation platform('io.micrometer:micrometer-tracing-bom:latest.version')
implementation 'io.micrometer:micrometer-tracing-bridge-otel'

```

#### 2. ObservationRegistry
```java
@Configuration
public class ObservationConfig {
    
    @Bean
    public ObservationRegistry observationRegistry() {
        return ObservationRegistry.create();
    }
    
    // 或者更完整的配置
    @Bean
    public ObservationRegistry observationRegistry(Ometer meterRegistry) {
        ObservationRegistry registry = ObservationRegistry.create();
        
        // 配置观察者
        registry.observationConfig()
            .observationHandler(new DefaultMeterObservationHandler(meterRegistry))
            .observationHandler(new OnlyLogWhenSlowSpanCondition())
            .observationFilter(new KeyValuesFilter());
            
        return registry;
    }
}
```

#### 3. 配置追踪系统
```yaml
# application.yml
management:
  tracing:
    sampling:
      probability: 1.0
  zipkin:
    tracing:
      endpoint: http://localhost:9411/api/v2/spans
```

##### 4、自定义观测器
```java
@Component
public class CustomObservationHandler implements ObservationHandler<Observation.Context> {
    
    @Override
    public void onStart(Observation.Context context) {
        System.out.println("开始观测: " + context.getName());
    }
    
    @Override
    public void onStop(Observation.Context context) {
        System.out.println("结束观测: " + context.getName());
        Timer.Sample sample = context.get(Timer.Sample.class);
        if (sample != null) {
            sample.stop(Timer.builder(context.getName())
                .register(MeterRegistry));
        }
    }
    
    @Override
    public boolean supportsContext(Observation.Context context) {
        return true;
    }
}

```

#### 5. 创建观测器
```java
@Service
public class MyLLMService {
    
    private final ObservationRegistry observationRegistry;
    
    public MyLLMService(ObservationRegistry observationRegistry) {
        this.observationRegistry = observationRegistry;
    }
    
    public String callLLM(String prompt) {
        return Observation.createNotStarted("llm.call", observationRegistry)
            .lowCardinalityKeyValue("model", "gpt-3.5-turbo")
            .observe(() -> {
                // 执行 LLM 调用
                return llmClient.call(prompt);
            });
    }
}

```
